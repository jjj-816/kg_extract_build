## 3. V1 构建原则

1. 每份目标方案实例化全部 42 个审核任务。
2. 任务列表由已发布任务库固定，不由 LLM 临时生成。
3. 没有发现问题的任务也必须保存审核执行记录。
4. 标题缺失但内容可通过字段和表头可靠定位时，不直接判章节缺失。
5. 审核输入保留自然结构，不将有序工序拆成全部两两关系。
6. 规范不符合必须具有目标方案证据和完整适用规范原文。
7. 图检索线索用于查询扩展和合理性判断，不直接证明违规。
8. 5.1 JSA 表格的步骤—危害—控制措施缺项只由既有 JSA 规则引擎处理。
9. 封面签字必须具备；整页照片或签 字图片转人工核验，不判断真伪。
10. 附录中按流程打印后完成的内容填写、勾选、日期、签字、盖章和验收标记为待线下完善。
11. 项目、地点、日期、工作内容、人员和设备在正文与附录之间需要保持一致。
12. 作业类型由审核员多选确认，不依赖系统从不规范文本自动推断。

V1 将施工内容区分为：

- 核心工作项：本次工程实际需要完成的重点工作，如电缆沟开挖、电缆敷设和设备安装；
- 过程控制步骤：保障施工正常开展的准备和管理步骤，如作业前准备、开工条件确认、安全技术交底、监护和收尾。

主要工作量列出核心工作项，施工顺序同时包含核心工作项和过程控制步骤。两者采用覆盖关系检查，不要求逐项相等。

## 7. 跨章节一致性关系

V1 不单独建立大量跨章节任务，而是在对应业务任务中配置以下一致性检查：

| 主信息 | 应保持一致的位置 |
|---|---|
| 工程名称 | 封面、2.1、附录 A、B、C、E |
| 建设或作业地点 | 2.2、附录 B、C、E |
| 施工单位 | 封面、2.3/2.4参建单位、附录 A、B、C、D |
| 编制和作业年份 | 封面、2.3计划时间、附录 C、E |
| 核心工作项 | 3.3、4.1、分项技术措施、5.1、附录 A、E；附录 C 在线下填写后再核对 |
| 过程控制步骤 | 4.1、分项技术措施和5.1；允许不出现在3.3主要工作量中 |
| 施工步骤 | 4.1、分项技术措施、5.1、附录 E；附录 C 在线下填写后再核对 |
| 风险与措施 | 4.2、5.1、5.2、附录 B、C、E |
| 人员和工种 | 3.1、3.2、施工组织机构、资格证明 |
| 设备和工具 | 3.2、分项技术措施、附录 D |
| 作业类型 | 人工审核上下文、风险作业编号、4.2、5.2、附录 E |

跨章节不一致首先形成“信息问题”。只有明确适用规范规定必须一致或必须包含某项内容时，才可另行形成“规范不符合”。

## 9. V1 明确不做

- 不自动判断文档包含哪些作业类型；
- 不对封面签字、证件、印章进行真实性识别；
- 不把图谱三元组直接作为规范不符合证据；
- 不将电子稿中按流程线下完成的填写、勾选、日期、签字、盖章和验收判为内容缺失；
- 不对附录 B 的模板固定培训文本重复执行规范 RAG；
- 不对电子稿中通常留空的附录 C 交底内容执行合规语义审核；
- 不要求附录 E 必须复制完整 JSA 或与 JSA 逐行相同；
- 不由 LLM 动态创建、删除或跳过固定审核任务；
- 不将5.1 JSA缺项重复交给合规提示词或合理性提示词；
- 不自动给整份方案输出机器“通过/不通过”结论。
